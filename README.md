# EasterEgg.js
This is just a simple easteregg that you can add to a website. Type ⬆️⬆️⬇️⬇️↩️ to activate


# How to add to site

Just put the following line in your html. This should sideload as well and not interfere with the websites initial load since it is asynchronously loaded.
```
<script src="https://cdn.jsdelivr.net/gh/o850cHQk/EasterEgg.js/easteregg.js" async></script>
```
